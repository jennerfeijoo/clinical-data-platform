# Pilot acceptance checklist

Use this checklist at the final joint review.

## Reproducibility

- [ ] exact source checksums and receipts recorded;
- [ ] exact release artifact and commit recorded;
- [ ] contract versions and hashes recorded;
- [ ] source rows reconcile to accepted, rejected, or explicitly omitted rows;
- [ ] cohort parameters and source runs recorded;
- [ ] independent rerun reproduces the agreed fingerprint.

## Data quality

- [ ] identifiers and parent relationships assessed;
- [ ] missingness denominators agreed;
- [ ] units and terminology mappings reviewed;
- [ ] schema drift and corrections documented;
- [ ] quarantine and rejection reasons reviewed;
- [ ] clinical interpretation limitations accepted.

## Governance and security

- [ ] data-use approval recorded;
- [ ] identifiability classification recorded;
- [ ] access and processing location approved;
- [ ] retention and deletion completed or scheduled;
- [ ] no identifiable data present in repository, logs, reports, or support records;
- [ ] residual risks assigned an owner.

## Decision

- [ ] stop;
- [ ] revise and repeat;
- [ ] expand under a new approved scope.

A successful technical pilot does not authorize production healthcare use or patient-specific decision-making.
